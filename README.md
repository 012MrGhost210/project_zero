# Мониторинг использования диска (read-only)

Streamlit-приложение для **только чтения** аналитики занятости диска: размер выбранного каталога, свободное место на томе (через `os.statvfs`), самые тяжёлые подпапки и файлы.

## Важно: только чтение

Приложение **ничего не записывает** под указанными путями:

- нет создания, изменения, удаления, перемещения, `chmod`
- нет «очистки», корзины, переименования
- сканирование через `os.scandir` / `pathlib` и объём тома через `os.statvfs`

Если операция могла бы писать на диск в анализируемых каталогах — её в приложении нет.

## Требования

- Python 3.10+
- Зависимости из `requirements.txt`

## Установка и запуск

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py --server.port 8507 --server.address 0.0.0.0
```

Откройте в браузере: [http://127.0.0.1:8507](http://127.0.0.1:8507)

## Как пользоваться

1. В боковой панели укажите **корневой / основной каталог** (контекст, часто точка монтирования).
2. Укажите **наблюдаемый каталог** — папку для анализа.
3. Задайте топ N и интервал автообновления (0 = только вручную).
4. Смотрите метрики размера, свободное место на томе и таблицы тяжёлых папок/файлов.

## Ограничения

- Симлинки пропускаются (чтобы не уходить на другие тома и не зациклиться).
- Нет прав на каталог — запись в предупреждениях, сканирование продолжается где возможно.
- На очень больших деревьях сканирование может занять время; уменьшите область наблюдения.
